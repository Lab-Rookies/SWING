# SWING Archive — 랩실막내들

**2026 SWING Silicon Valley Program Archive**

본 콘텐츠는 숙명여자대학교 SW중심대학사업의 일환으로 운영된 글로벌 프로그램 **SWING**을 통해 경험한 **실리콘밸리 현직자 인터뷰와 Agentic AI Summit 세션**을 기록하고 공유하기 위해 제작한 GitHub Pages 기반의 아카이브입니다.

현직자와의 인터뷰에서 들은 커리어와 연구·산업 현장의 이야기부터 Agentic AI Summit에서 접한 최신 AI 기술과 인사이트까지, 프로그램을 통해 배우고 느낀 내용을 하나의 웹사이트에 정리했습니다.
